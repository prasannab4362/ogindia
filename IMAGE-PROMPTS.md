# Only Garments India: image prompts (studio cut-outs like the reference)

The reference site looks premium because of its **AI studio images**: models and sarees cut out on a plain background. Generate each image below with your image tool (Gemini / Imagen, or Omni if it makes stills). Save it in **`assets/products/`** with the exact file name shown, then refresh the site. Each image automatically replaces the stock photo in its slot. No code changes are needed.

**Save cut-outs (looks, silks, rack) as PNG with a transparent background.** If your tool can't make a transparent background, ask for a pure white background and remove it with any free background remover. A JPG on a plain white background also works.

**Add this to every prompt:** *photorealistic studio product photo, soft even light, true fabric texture and real gold zari, accurate Indian draping, natural hands and face, no text, no logo, no watermark.*
